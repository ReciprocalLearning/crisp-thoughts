# Azure Reservations: Eligible Resource Types and Details

Azure Reservations allow you to save costs by committing to one-year or three-year plans for various Azure resources. By purchasing reservations, you receive discounted rates compared to pay-as-you-go pricing, often saving up to 72% or more depending on the resource and term.

## Eligible Resource Types for Azure Reservations

Azure Reservations cover a broad range of resource types, including but not limited to:

* **Virtual Machines (VMs):** Reserved VM Instances for compute resources.
* **Azure SQL Database:** Reserved capacity for single databases and elastic pools.
* **Azure Cosmos DB:** Reserved throughput capacity.
* **App Service Environments:** Reserved capacity for App Service plans.
* **Azure Blob Storage:** Reserved capacity for Blob storage tiers.
* **Azure Data Explorer:** Reserved capacity for clusters.
* **Azure Synapse Analytics:** Reserved capacity for SQL pools.
* **Azure Dedicated Hosts:** Reserved physical servers for VM deployment.
* **Azure Kubernetes Service (AKS):** Reserved nodes (in preview or specific regions).
* **Azure Cache for Redis:** Reserved cache instances.
* **Azure Managed Disks:** Reserved capacity for managed disk storage.
* **Log Analytics:** Reserved capacity for Log Analytics workspace data ingestion.
* **Azure Defender for Cloud:** Reserved capacity for Azure Defender plans and security features.

## Reservation Terms and Payment Options

* **Term Lengths:** Reservations can be purchased for 1-year or 3-year terms. Some services may offer longer terms.
* **Payment Options:** You can pay upfront or choose monthly payments. The total cost remains the same regardless of payment method.
* **Discount Application:** Discounts apply automatically to matching resources in your subscription.

## Benefits of Azure Reservations

* Significant cost savings compared to pay-as-you-go pricing.
* Predictable budgeting with fixed reservation costs.
* Flexibility to exchange or cancel reservations under certain conditions.
* Discounts apply without affecting the runtime state of your resources.

## How to Purchase and Manage Reservations

* Use the Azure portal, CLI, or API to purchase reservations.
* Azure Advisor can help identify resources eligible for reservations.
* Monitor reservation usage and optimize through the Azure Cost Management tools.

This overview provides a summary of Azure Reservations, their eligible resource types, terms, and benefits to help you plan cost-effective cloud deployments.
